# Notes

Open **Notes** beside the layout button, or cycle through Columns, Tabs, Calendar, and Notes. Notes has its own search and New note button.

Each note has a title, a plain-text body, and optional hashtags. Write tags freely, separated by spaces or commas. Existing tags offer an inline completion: press Tab or the right arrow at the end of the input, or tap the completion below it. Enter and space add tags; click a tag's × to remove it. Tags ignore case and preserve the spelling already used.

Search combines words and partial hashtags, e.g. `#Parallel ending`. Click a tag on a note or one of the eight quick tags to filter. Quick tags prioritize frequent use, then recent updates. Notes are ordered by their last edit.

Notes are saved locally with the existing save and included in online sync and JSON backups. No database migration is required. Older backups without notes leave existing notes alone. Cancel and Escape ask before discarding editor changes. Notes use neutral pastel styling without a color/category system.
